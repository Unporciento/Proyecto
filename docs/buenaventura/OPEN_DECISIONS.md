# Decisiones abiertas

- Proveedor, modelo, coste, disponibilidad regional y consentimiento exacto.
- Interfaz para seleccionar contexto y explicar sus límites.
- Formato definitivo de referencias y fragmentos para cada tipo de documento.
- Cualquier memoria persistente distinta del estado cualitativo mínimo de `09`,
  incluyendo conversación, perfil o interpretación académica.
- Umbrales de presupuesto tras medición real en PC y móviles.

Nada de esta lista autoriza implementación. No se debe elegir una opción por
conveniencia técnica sin una fase y aprobación separadas.
